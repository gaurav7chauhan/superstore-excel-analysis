# Superstore Sales Analysis in Excel

I'm using the Superstore sales dataset to figure out which regions, categories and products actually make money, and which ones quietly lose it.

## About the data
The dataset comes from Kaggle and has 9,994 orders across 21 columns, covering sales, profit, discounts, customers and regions.
